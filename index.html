HTML Embed es un componente creado para A-Frame. El componente incrustación de HTML, permite que se inserte html arbitrario en su escena Aframe. Le permite actualizar la pantalla dentro de A-Frame solo manipulando el DOM como se haría normalmente.

Además de representar el html en la escena A-Frame, permite Interacción. La mayoría de los pseudoselectores css como hover, active, focus y el objetivo debería funcionar con la interactividad habilitada sin ninguna modificaciones a su css. Los eventos del mouse se pueden adjuntar al html elementos como de costumbre.
